# 01 — Receta txAdmin

Aquí irá `recipe.yaml`, la receta para instalar ZENTRIKA RP desde txAdmin.

## Pendiente antes de activar la receta

1. Publicar el paquete de recursos verificado en GitHub Releases (el ZIP principal supera el límite normal de archivos de GitHub).
2. Publicar el paquete SQL seleccionado como asset de Release o incorporar los SQL individualmente si su licencia lo permite.
3. Sustituir en la receta las URL de descarga por las URL reales de esos assets.
4. Validar la receta en un servidor de prueba antes de usarla en producción.

No ejecutar una receta con enlaces de ejemplo o sin verificar.
