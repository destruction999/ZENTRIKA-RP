# Recursos FiveM — ZENTRIKA RP

Recursos se organizarán por categoría. Esta estructura es una base; **no contiene scripts de servidor ni recursos reales todavía**.

## Categorías
- [core] Framework y recursos esenciales
- [standalone] Recursos independientes
- [jobs] Trabajos civiles
- [police] Policía y EMS
- [mechanic] Mecánicos
- [vehicles] Vehículos y concesionarios
- [garages] Garajes y llaves
- [custom] Recursos personalizados

Mantén cada recurso completo en su propia carpeta y revisa sus dependencias antes de cambiar el orden de inicio en server.cfg.
