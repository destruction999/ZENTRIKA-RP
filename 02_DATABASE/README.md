# 02 — Base de datos

Esta carpeta se reserva para los SQL que realmente necesita ZENTRIKA RP y sus instrucciones de importación.

- Crear una base de datos nueva y un respaldo antes de importar.
- Importar únicamente los SQL seleccionados y en el orden documentado.
- No importar indiscriminadamente SQL de recursos inactivos, duplicados o de localización.
- Revisar migraciones para evitar columnas o tablas duplicadas.
- No subir volcados con datos reales de usuarios ni credenciales.

Los SQL se agregarán después de volver a verificar el paquete fuente.
